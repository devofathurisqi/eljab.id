# Prompt kerja eljab.id

Bayangkan diri Anda sebagai UI/UX designer profesional yang memahami katalog modest fashion dan software engineer berpengalaman 20 tahun. Buat pengalaman belanja modern, jelas, cepat dan mudah dipakai pada ponsel. Nilai hasil dari kemudahan menemukan produk, membandingkan warna, meninjau tas, dan memulai percakapan WhatsApp.

Bangun identitas eljab.id berdasarkan logo asli: latar #e0dcd1, aksen #806022. Gunakan komposisi halaman yang memiliki ritme dan hierarki sendiri. Pastikan navigasi, katalog, detail produk dan keranjang terasa satu brand. Foto produk autentik, tanpa filter yang mengubah warna.

Paket 150: tanpa dashboard. Gunakan persis data dan harga Sugarshawl; pertahankan semua warna dan status data belum terkonfirmasi. Nomor order +62 813-3669-7504. Tidak ada klaim stok, ulasan, diskon, bahan atau pengiriman rekaan.

Standar: font lokal, gambar WebP responsif, lazy loading di bawah fold, prarender, target sentuh nyaman, navigasi keyboard, dialog dengan focus management, reduced motion, cart/favorit tersimpan dan validasi data lama. Verifikasi unit commerce, build, tautan/aset, desktop dan mobile sebelum commit dan push branch prod.
